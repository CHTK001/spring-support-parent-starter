## 五、已知边界（经真实启动确认）

| 边界 | 处理方式 |
|:-----|:---------|
| 文件目录不存在 | 优雅降级，不抛异常，映射数为 0 |
| 数据库表为空 | 加载 0 条映射，不报错 |
| 无 DataSource 场景（文件模式） | 不影响文件映射加载 |
| params 非法 JSON | WARN 降级 `params={}`，映射照常加载执行 |
| 映射表不存在（坏表前缀） | `ERROR 加载失败` 被捕获，Server 正常启动 |
| properties 字段数组语法 | `mappings[0].sourceField=` 不生效（mappings=[]），仅 YAML/JSON 可靠 |
| 数据库模式默认嵌入 H2 | `--datasync.mode=database` 无外网也能真实启动；`--datasync.db=mysql` 才连生产 MySQL |
| TcpSyncClient 掉线语义 | 掉线后仅回调 `onError`，`connected` 标志不复位；重连须显式 `disconnect()` + `connect()` |
