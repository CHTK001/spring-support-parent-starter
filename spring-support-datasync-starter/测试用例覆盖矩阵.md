### 数据库->数据库同步（目标：172.16.0.40）

```
源数据库（本地 H2 / 172.16.0.40）
├── datasync_mapping        ← 映射定义表
├── datasync_field_mapping  ← 字段映射表
└── 业务数据表              ← 待同步数据

DataSync 流程：
1. DatabaseMappingLoader 启动时从源库加载 mapping 配置
2. DataSyncServer 按 mapping 定义调度任务
3. Source 从源数据库读取数据
4. FieldMappingConverter 字段转换
5. Sink 写入目标数据库（172.16.0.40）
```

配置示例（application-db.yml）：
```yaml
plugin:
  datasync:
    enabled: true
    mapping-source: database
    database-mapping:
      enabled: true
      table-prefix: datasync_
      auto-init-table: true
      cron: "0/5 * * * * ?"

spring:
  datasource:
    url: jdbc:mysql://172.16.0.40:3306/your_db  # 目标库
    username: user
    password: pass
```
