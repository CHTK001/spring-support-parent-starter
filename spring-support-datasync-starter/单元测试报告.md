## 启动类

单一启动类，通过参数切换映射来源：

- 类：`com.chua.starter.datasync.support.DataSyncApplication`
- 参数：
  - `--datasync.mode=file`（默认）：从文件目录加载映射
  - `--datasync.mode=database`：从数据库表加载映射

## 执行命令

```bash
# 文件模式
mvn spring-boot:run -Dspring-boot.run.main-class=com.chua.starter.datasync.support.DataSyncApplication

# 数据库模式
mvn spring-boot:run -Dspring-boot.run.main-class=com.chua.starter.datasync.support.DataSyncApplication ^
  -Dspring-boot.run.jvmArguments=-Ddatasync.mode=database
```

## 测试结果详情

### 1. 文件模式（mapping-source=file）

映射目录：`./src/main/resources/datasync/mappings`

| 映射ID | 文件 | source | sink | 字段映射 |
|:-------|:-----|:-------|:-----|:---------|
| user-sync | user-sync.yaml | user-source | user-sink | name→user_name(toString)、age→user_age(toInteger) |
| order-sync | order-sync.json | order-source | order-sink | orderId→order_id(toString)、amount→order_amount(toDouble) |

结果：`已加载映射数=2`，DataSyncServer 启动成功 ✅

### 2. 数据库模式（mapping-source=database）

数据源：嵌入式 H2（`schema.sql` 建表 + 测试数据），表前缀 `datasync_`

| 映射ID | input | source | output | sink | 字段映射 |
|:-------|:------|:-------|:-------|:-----|:---------|
| db-user-sync | user-input | user-source | user-output | user-sink | name→user_name(toString) |

结果：`已加载映射数=1`，DataSyncServer 启动成功 ✅

## 关键修复记录

| 问题 | 修复 |
|:-----|:-----|
| 两个启动类同包冲突（ConflictingBeanDefinitionException） | 合并为单一 `DataSyncApplication`，用 `datasync.mode` 切换 |
| datasource-starter 注册动态数据源覆盖自定义 H2（`mapping-source=database` 时 `DatabaseMappingLoader` 注入空库/SQLite 兜底） | `@SpringBootApplication` 排除 `DataSourceInspect`，自定义 H2 成为唯一 DataSource |
| Spring Boot `dataSourceScriptDatabaseInitializer` 重复执行 schema.sql 导致主键冲突 | `spring.sql.init.mode=never`，表由 EmbeddedDatabaseBuilder 统一建 |
| `exec:java` 传递 `-Ddatasync.mode` 到不了子进程 | 改用 `spring-boot:run` + `-Dspring-boot.run.jvmArguments` |
