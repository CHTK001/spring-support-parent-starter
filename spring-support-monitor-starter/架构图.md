# spring-support-monitor-starter 架构图

## 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                       Web 层                                │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ Controller / RestController + OpenAPI (Swagger v3)  │  │
│  │  - MonitorController          (资产 CRUD)           │  │
│  │  - MonitorTaskController      (任务 CRUD + 触发)     │  │
│  │  - MonitorMetricConfigController (解析规则 CRUD)    │  │
│  │  - MonitorGatewayController   (网关 CRUD)           │  │
│  │  - MonitorConfigController    (全局配置 CRUD)       │  │
│  │  - MonitorMetricController    (时序查询)            │  │
│  │  - MonitorRedisOperationController (Redis 操作)     │  │
│  │  - MonitorAiController        (AI 分析 SSE)         │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│                      Service 层                             │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ @Cacheable(@CacheEvict)                              │  │
│  │  - MonitorService              Cache: monitor        │  │
│  │  - MonitorTaskService          Cache: monitorTask    │  │
│  │  - MonitorMetricConfigService  Cache: monitorMetricConfig│
│  │  - MonitorGatewayService       Cache: monitorGateway │  │
│  │  - MonitorConfigService        Cache: monitorConfig  │  │
│  └──────────────────────────────────────────────────────┘  │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 业务编排                                              │  │
│  │  - MetricService        (指标采集写入 + 聚合)         │  │
│  │  - MonitorOperationService (Redis 操作转发)          │  │
│  │  - MonitorAiAnalysisService (ChatClient 流式)        │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│                 调度层 + Provider 层 (Reactive)             │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ MonitorScheduler (@Scheduled 10s tick)               │  │
│  │  - 读 ms_monitor_task (@Cacheable)                   │  │
│  │  - Trigger.nextTriggerTime() 判断                    │  │
│  │  - Flux.fromIterable(task)                           │  │
│  │  - .flatMap(concurrency=50)                          │  │
│  │  - .subscribeOn(boundedElastic)                      │  │
│  │  - .buffer(200)                                      │  │
│  │  - .onBackpressureBuffer(10_000, DROP_OLDEST)        │  │
│  └──────────────────────────────────────────────────────┘  │
│                          │                                  │
│                          ▼                                  │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ ProviderRegistry   (双键索引)                          │  │
│  │  Map<ServiceType, Map<ProviderType, MetricProvider>>  │  │
│  └──────────────────────────────────────────────────────┘  │
│                          │                                  │
│  ┌───────────────────────┴────────────────────────────────┐│
│  │  MetricProvider SPI                                  ││
│  │  ├─ ServerLocalProvider      (oshi, macOS 跳过)      ││
│  │  ├─ ServerTerminalProvider   (SSH)                   ││
│  │  ├─ ServerHttpProvider       (HTTP)                  ││
│  │  ├─ PrometheusProvider       (Prometheus API)        ││
│  │  ├─ RedisLocalProvider       (Lettuce INFO)          ││
│  │  └─ PrometheusProvider       (server/redis/db ...)   ││
│  └───────────────────────────────────────────────────────┘│
│  ┌───────────────────────────────────────────────────────┐│
│  │  OperationProvider SPI                                ││
│  │  ├─ RedisOperationProvider  (scan/get/set/del/expire) ││
│  └───────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│                       数据层                                │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ MyBatis-Plus BaseMapper (CRUD)                       │  │
│  │  + insertBatch(批量入库)                              │  │
│  └──────────────────────────────────────────────────────┘  │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 数据库(MySQL / H2 / 达梦)                             │  │
│  │  ms_monitor / ms_monitor_task / ms_monitor_config    │  │
│  │  ms_monitor_metric / _cpu / _memory / _disk / ...   │  │
│  │  ms_monitor_redis_metric / ms_monitor_gateway       │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│                外部依赖 (Spring Boot Starter)              │
│  - spring-support-cache-starter (TenantedKeyGenerator)     │
│  - spring-support-mybatis-starter (BaseMapper)             │
│  - spring-support-datasource-starter                       │
│  - spring-support-swagger-starter (knife4j + OpenAPI)      │
│  - spring-support-ai-starter  (ChatClient)                 │
│  - spring-support-job-starter  (可复用 Trigger)            │
│  - utils-support-common-starter (Trigger / Cron)           │
│  - utils-support-oshi-starter (本地采集)                    │
│  - utils-support-ssh-starter   (终端)                      │
│  - utils-support-redis-starter (Lettuce)                   │
└─────────────────────────────────────────────────────────────┘
```

## 数据流与缓存层

```
         ┌──────────────────────────────────────────┐
CRUD ──►│ Spring Cache Layer                         │
         │  - multi-level (Caffeine + Redis)         │
         │  - tenantedKeyGenerator                   │
         └──────────────┬───────────────────────────┘
                        │ bypass for 时序表
                        ▼
         ┌──────────────────────────────────────────┐
         │ MyBatis-Plus BaseMapper                   │
         │  - insertBatch (200/batch)                │
         └──────────────┬───────────────────────────┘
                        ▼
         ┌──────────────────────────────────────────┐
         │ Database                                   │
         │  - 配置型 5 张表 @Cacheable                │
         │  - 时序 9 张表 不缓存, 索引加速            │
         └──────────────────────────────────────────┘
```
