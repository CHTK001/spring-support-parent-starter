## 关键设计决策

| 决策 | 说明 |
|---|---|
| 表前缀 | 统一 `ms_monitor_`，避免 `ms_server_` 局限 |
| 实体基类 | 5 个业务实体继承 `SysBase`（继承 BaseMapper 自动填充），9 个时序实体直接 `Serializable` |
| 双键路由 | `MetricProvider` 按 `(ServiceType, ProviderType)` 双键索引 |
| 操作 SPI | `OperationProvider` 按 `ServiceType` 单键索引 |
| 缓存 | 5 个 cache 名 + key 前缀 `monitor.*`, 使用 `spring-support-cache-starter` 默认 `tenantedKeyGenerator` |
| 采集入口 | `@Scheduled(fixedRate=10s)` + `Trigger` 判断 cron 是否到达 |
| 入库方式 | `Mono.fromRunnable().subscribeOn(boundedElastic)` + `MyBatis-Plus` `insertBatch` |
| 背压 | `Flux.buffer(200)` + `onBackpressureBuffer(10000, DROP_OLDEST)` |
| AI | 通过 `spring-support-ai-starter` ChatClient 流式响应 (SSE) |
