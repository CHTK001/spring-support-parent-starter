# 教育AI模块开发计划

> 模块：`spring-support-eduai-starter`
> 版本：`4.0.0.42`
> 参考模块：`spring-support-message-starter`

## 一、模块定位

教育AI模块为学校/培训机构提供 AI 辅助教学能力，覆盖**题库管理、AI组卷、AI阅卷、知识库、错题库、考试管理**六大核心能力，是 AI 与教育教学场景的结合落地。

## 二、表设计规范

- 所有表以 `edu_` 为前缀。
- 所有字段以其表名作为前缀（例如 `edu_question` 表 → `question_id`）。
- 统一使用 BIGINT 自增主键、`create_time` / `update_time` 时间字段、`create_by` / `update_by` 审计字段。

| 表名 | 说明 | 对应实体 |
|------|------|----------|
| `edu_knowledge_point` | 知识点（树形结构） | EduKnowledgePoint |
| `edu_question` | 题目库 | EduQuestion |
| `edu_paper` | 试卷 | EduPaper |
| `edu_paper_question` | 试卷-题目关联 | EduPaperQuestion |
| `edu_exam` | 考试 | EduExam |
| `edu_answer_sheet` | 答题卡 | EduAnswerSheet |
| `edu_marking_result` | 阅卷结果 | EduMarkingResult |
| `edu_wrong_question` | 错题记录 | EduWrongQuestion |
| `edu_knowledge_doc` | 知识库文档 | EduKnowledgeDoc |

## 三、功能清单与进度

### 1. 题库管理（已完成）

- [x] 实体 / Mapper / Service / Controller
- [x] 分页查询、详情、新增/更新、批量导入、逻辑删除
- 路由：`/v2/edu/question/**`

### 2. AI组卷（已完成）

- [x] 实体 / Mapper / Service / Controller
- [x] 分页查询、试卷详情（含题目）、AI生成试卷、替换题目
- 路由：`/v2/edu/paper/**`

### 3. AI阅卷（已完成）

- [x] 实体 / Mapper / Service / Controller
- [x] 提交答题卡、轮询阅卷结果、教师确认评分
- 路由：`/v2/edu/marking/**`

### 4. 知识库（已完成）

- [x] 知识点：树形查询、新增/更新、级联删除
- [x] 知识文档：分页查询、上传、语义检索、删除
- 路由：`/v2/edu/knowledge-point/**`、`/v2/edu/knowledge-doc/**`

### 5. 错题库（已完成）

- [x] 实体 / Mapper / Service / Controller
- [x] 记录错题、分页查询、生成复习卷、更新掌握度
- 路由：`/v2/edu/wrongbook/**`

### 6. 考试管理（已完成）

- [x] 实体 / Mapper / Service / Controller
- [x] 分页查询、详情、创建、更新、删除
- 路由：`/v2/edu/exam/**`

## 四、目录结构

```
spring-support-eduai-starter
├── pom.xml
├── README.md
└── src/main
    ├── java/com/chua/starter/eduai
    │   ├── configuration/      # 自动装配
    │   ├── controller/         # REST 控制器
    │   ├── mapper/             # MyBatis-Plus Mapper
    │   ├── model/
    │   │   ├── dto/            # 请求 DTO
    │   │   ├── vo/             # 响应 VO
    │   │   └── *.java          # 实体
    │   └── service/
    │       └── impl/           # 服务实现
    └── resources
        ├── META-INF/spring/    # 自动装配声明
        └── db/init/            # 建表脚本
```
