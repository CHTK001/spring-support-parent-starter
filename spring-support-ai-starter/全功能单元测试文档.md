# 全功能单元测试文档

> 本模块 `spring-support-ai-starter` 的接口验证采用 **Spring Boot 真实启动 + HTTP 请求** 方式，
> 不使用 JUnit / Mockito。通过 `spring-boot:run` 启动完整服务（H2 内存数据库 + db/init 初始化脚本），
> 服务就绪后逐接口发起真实 HTTP 请求校验响应，覆盖 AI 模块全业务功能链路。

---

## 1. 验证方式

### 1.1 一键验证脚本（推荐）

在 `spring-support-parent-starter` 根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File spring-support-ai-starter/verify-api.ps1
```

脚本自动完成：
1. **编译** spring-support-ai-starter
2. **启动服务**（`mvn spring-boot:run`，`local` profile：H2 内存库 + db/init 脚本）
3. **等待就绪**（轮询端口 8091）
4. **逐接口验证**（142 项，覆盖全部核心业务 + 真实 LLM/视觉/RAG/人脸/语音链路 + OpenAI 扩展边界 + 统一能力清单 + 人脸辅助能力）
5. **输出 PASS/FAIL 汇总** 并关闭服务

### 1.2 手动启动

```bash
# 方式一：spring-boot:run 启动（推荐）
mvn -o -pl spring-support-ai-starter spring-boot:run -Dspring-boot.run.profiles=local -Dpmd.skip=true

# 方式二：打包后启动
mvn -o -pl spring-support-ai-starter package -DskipTests
java -jar spring-support-ai-starter/target/spring-support-ai-starter-4.0.0.42.jar --spring.profiles.active=local
```

服务启动后访问：`http://localhost:8091/api/ai`

> 本地 profile 已内置：H2 内存库、db/init 脚本自动建表+种子数据、关闭 OAuth/协议服务器/文件系统/RAG 外部引擎。

## 2. 本地启动配置

`src/main/resources/application-local.yml`（不改动生产 `application.yml`）：

```yaml
server:
  port: 8091
  servlet:
    context-path: /api/ai

spring:
  datasource:
    driver-class-name: org.h2.Driver
    url: jdbc:h2:mem:ai_local;MODE=MySQL;DATABASE_TO_LOWER=TRUE;CASE_INSENSITIVE_IDENTIFIERS=TRUE;DB_CLOSE_DELAY=-1;NON_KEYWORDS=VALUE
  ai:
    rag:
      enabled: false
      vector-storage: memory

plugin:
  oauth:
    enable: false       # 关闭外部 OAuth 鉴权
  protocol:
    enable: false
  filesystem:
    enable: false
  datasource:
    script:
      enable: true      # 启动时执行 db/init/*.sql
      scan-mode: ONCE
```

## 6. 验证中发现并修复的问题

### 6.1 AppKey 逻辑删除失效（已修复）

**问题**：`SysAiAppKeyServiceImpl.deleteById` 通过 `updateById(entity)` 设置 `delete=1`，
但实体字段标注了 `@TableLogic`，MyBatis-Plus 的 `UPDATE_BY_ID` 不会更新逻辑删除字段
（该字段被当作 `WHERE delete=0` 条件），导致逻辑删除实际不生效，已删除的 AppKey 仍可校验通过。

**修复**：改用 MyBatis-Plus 内置 `mapper.deleteById(id)`（识别 `@TableLogic` 自动生成 `SET delete=1`）。

```java
// 修复前：无效（@TableLogic 字段不会出现在 SET 中）
SysAiAppKey entity = new SysAiAppKey();
entity.setSysAiAppKeyId(id);
entity.setSysAiAppKeyDelete(1);
return sysAiAppKeyMapper.updateById(entity) > 0;

// 修复后：正确执行逻辑删除
return sysAiAppKeyMapper.deleteById(id) > 0;
```

### 6.2 角色逻辑删除失效（已修复）

`SysAiRoleServiceImpl.deleteById` 存在相同问题（`sysAiRoleDelete` 标注 `@TableLogic`），
已同样改用 `sysAiRoleMapper.deleteById(id)`。

> ⚠️ **排查结论**：`SysAiToken`、`SysAiGroup` 的 `delete` 字段**未**标注 `@TableLogic`，
> 其 `updateById` 更新普通字段方式有效，无需修改。

### 7.8 Converter 集合/数组转换扩展（公共工具）

### 7.12 CodeFormer 人脸修复真实推理修复（新增）
