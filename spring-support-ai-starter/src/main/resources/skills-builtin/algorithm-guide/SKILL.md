# 算法与数据结构指南

## 一、复杂度分析

- 先估规模：n ≤ 20 允许指数级，n ≤ 500 允许 O(n³)，n ≤ 1e4 允许 O(n²)，1e5+ 需要 O(n log n) 及以下。
- 均摊分析：动态数组 push、并查集路径压缩都是均摊 O(1)。
- 空间换时间是常态：前缀和、哈希计数、单调栈都是用空间降时间。

## 二、核心数据结构选型

- 数组：随机访问、尾部增删；链表：任意位置增删、需要稳定迭代器。
- 哈希表：O(1) 查重/计数/映射；有序场景用平衡树/跳表（TreeMap、SortedMap）。
- 堆：Top-K、合并 K 路、中位数（双堆）；单调栈/队列：下一个更大元素、滑动窗口最值。
- 并查集：连通性/分组；Trie：前缀检索；线段树/树状数组：区间统计与更新。

## 三、高频题型模板

- 双指针：有序数组两数之和、去重、快慢指针判环。
- 滑动窗口：最长无重复子串、最小覆盖子串——右扩左缩，用计数器维护窗口状态。
- 二分：边界二分模板（lower_bound/upper_bound），旋转数组、峰值寻找先画图定边界。
- DFS/BFS：网格类（岛屿、腐烂橘子）、树类（路径、深度）；回溯 = DFS + 现场恢复。
- 动态规划：定义状态 → 转移方程 → 初始化 → 遍历顺序；背包、 LIS、编辑距离、区间 DP 是母题。

```text
滑动窗口模板：
for r in 0..n:
    窗口加入 a[r]
    while 窗口不合法: 移出 a[l], l++
    用窗口更新答案
```

## 四、工程中的算法

- 选型先看操作分布：读多写少用不可变结构；频繁区间求和用前缀和/树状数组。
- 限流用令牌桶，去重用布隆过滤器，热点探测用 LFU/滑动窗口计数。
- 分页归并、一致性哈希、负载均衡轮询/加权，都是分布式里的「基础算法题」。

## 五、刷题路径

- 第一阶段：数组/字符串/哈希/双指针/栈队列（热题 100 前半）。
- 第二阶段：链表、二叉树（递归三要素）、BFS/DFS、回溯。
- 第三阶段：动态规划、贪心、图论（拓扑排序/最短路）、堆与单调结构。
- 每题限时 25~35 分钟；先讲思路再写代码，写完口头过一遍边界。

## 六、检查清单

- [ ] 能说清时间/空间复杂度与数据规模的关系
- [ ] 高频模板能默写：二分、滑动窗口、回溯、DP
- [ ] 会按场景选数据结构而不是全用哈希
- [ ] 边界（空、单元素、全相同、溢出）逐个过
