# 用户增长指南

## 一、增长模型与北极星

- 先建模型再谈打法：新用户 = 流量 × 转化率；活跃用户 = 新增 + 留存 - 流失；收入 = 活跃 × 付费率 × 客单。
- 北极星指标：最能代表「用户获得价值」的唯一指标（如周活跃学习时长、订单数），别把收入当唯一——收入是结果不是原因。
- 增长公式拆解：DAU = 新增激活 + 次日留存 + ... ；每个因子都能单独优化，定位最弱一环。

## 二、获客（Acquisition）

- 渠道三问：量够大吗？成本可算吗？质量可评估吗？——按 CAC（获客成本）与留存质量双维评估。
- 渠道类型：内容/SEO（慢但复利）、投放（快但贵）、BD/渠道合作、社群口碑、应用商店优化（ASO）。
- 渠道-信息-人群匹配：同一卖点在不同渠道换表达；投放素材每周迭代，跑量素材立刻复制变体。
- 落地页承接：广告语与落地页首屏一致，转化路径 ≤3 步；A/B 测试首屏与表单。

## 三、激活（Activation）

- 定义「啊哈时刻」：用户第一次感受到价值的行为（如首次完成一笔转账、学习满 10 分钟）。
- 新手引导只教一步：先让用户到达啊哈时刻，再展开功能教育；不要一上来填 20 个字段。
- 激活漏斗逐层埋点：注册 → 完成关键动作 → 达成激活标准；流失最多的一层优先优化。
- 外部触发辅助：注册后未激活的用户，用 push/短信/邮件按「未完成的那一步」定向提醒。

## 四、留存（Retention）

- 留存曲线画出来：次日/7日/30日留存；曲线走平的位置是产品价值成立的证据。
- 习惯回路：固定触发（每周报告、每日签到）+ 行动 + 变量奖励（成长、社交、惊喜）+ 投入（数据、关系、等级）。
- 流失预警：定义预警行为（连续 7 天未登录、使用频次骤降），触发挽回（权益、内容、人工回访）。
- 召回比拉新便宜，但召回的前提是「曾经体验过价值」；无价值产品召回只是续命。

## 五、裂变与推荐

- 裂变本质：给分享者社交货币或利益，给被邀者降低门槛（新人券双向奖励是经典结构）。
- 分享动力排序：有趣/有面 > 有用 > 有利；纯利益驱动易招羊毛党。
- 防薅羊毛：设备/手机号风控、同一用户限次、奖励延迟发放（确认行为真实后到账）。
- 病毒系数 K = 人均邀请数 × 邀请转化率；K>1 才自增长，多数产品靠 K≈0.2~0.5 的「增强器」模式。

## 六、增长实验（Growth Hacking 流程）

- 周期：分析数据找机会 → 提出假设（我们相信 X，若做 Y，指标 Z 将提升）→ 设计实验 → 上线 → 复盘沉淀。
- 实验优先级 ICE 打分：Impact（影响）、Confidence（信心）、Ease（易实现）。
- 一次只动一个变量；样本量按基线转化率与 MDE 预估，别第 3 天就下结论。
- 建立实验台账：假设、结果、结论、下一步——失败实验也是资产。

## 七、常见坑

- 只看拉新不看留存：漏桶里灌水。
- 北极星指标错位：把「注册量」当增长，激活与留存一塌糊涂。
- 补贴依赖：补贴停、增长停，说明没有找到真实价值主张。
- 数据 lag：转化归因窗口与渠道结算周期不一致，预算决策失真。

## 八、检查清单

- [ ] 北极星指标明确且全员对齐
- [ ] 获客渠道有 CAC 与质量分层
- [ ] 激活漏斗有埋点，啊哈时刻可衡量
- [ ] 留存曲线走平，流失预警在跑
- [ ] 增长实验有假设、台账与复盘
