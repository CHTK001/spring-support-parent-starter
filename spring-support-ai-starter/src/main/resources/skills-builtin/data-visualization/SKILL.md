# 数据可视化指南

## 一、图表选型

- 趋势：折线/面积；对比：柱状（类别少）或条形（类别名长）；占比：环形/堆叠柱（饼图慎用，超过 5 类改条形）。
- 分布：直方图/箱线图；相关性：散点/热力图；流向：桑基图；地理：地图（ choropleth 或散点）。
- 一图一结论：先问「这张图要让读者得出什么判断」，再选图。

## 二、坐标轴与数值

- Y 轴从 0 开始（柱状图尤其），截断轴会夸大差异；必须截断时明确标注。
- 数值格式：统一千分位、单位（万/亿）、小数位；时间轴等距，缺失日期补齐或断轴说明。
- 双轴图容易误读：两轴单位不同时用明确配色 + 轴标签区分，或拆成两张。

## 三、色彩与可读性

- 语义色固定：涨跌、好坏、目标线颜色全站一致；类别色用有区分度的调色板（色盲友好）。
- 一张图强调一个重点：重点用高饱和，其余降灰；别让图例比数据还多。
- 文字：标题说结论（「11 月新增用户环比 +18%」），副标题补口径（统计范围、时间粒度）。

## 四、大屏与报表

- 大屏优先布局：核心 KPI 在上（数值卡），趋势在中，明细在下；深色背景 + 高对比主色。
- 数字要「呼吸感」：大字号、等宽数字字体；动效仅用于数据更新，不做常驻动画。
- 报表表格：合计行、环比/同比列、异常标色；空数据给「—」而不是 0。

## 五、交互

- 默认展示最近一个有效周期，支持时间范围切换与下钻（总览→分类→明细）。
- tooltip 展示原始值与口径；筛选条件在图上可见（避免「看图不知道筛选了什么」）。
- 移动端降级：大屏组件在小屏改为可滚动卡片，不硬缩放。

## 六、检查清单

- [ ] 图表类型匹配数据关系
- [ ] 轴、单位、时间粒度标注完整
- [ ] 颜色语义一致，色盲可辨
- [ ] 标题直接给出结论与口径
- [ ] 空态/异常态（数据缺失、加载失败）有兜底展示
