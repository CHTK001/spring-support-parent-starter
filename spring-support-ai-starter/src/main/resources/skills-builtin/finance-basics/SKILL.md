# 个人理财基础

## 一、先理清现金流

- 记账 3 个月建立概念：固定支出（房租/房贷/水电）、弹性支出（餐饮/购物/娱乐）、储蓄投资。
- 50/30/20 法则起步：50% 必要支出、30% 想要支出、20% 储蓄投资；按实际比例调整，储蓄率是第一指标。
- 先付给自己：发薪日自动转出储蓄额度，剩下的再消费；靠「月底剩多少存多少」永远存不下。

## 二、应急金与负债

- 应急金：3~6 个月必要支出，放货币基金/活期理财，随取随用；这是所有投资的前提。
- 高息负债优先清偿：信用卡分期、消费贷利率往往 10%+，任何理财都难稳定跑赢——先还后投。
- 房贷等低息长期负债不必焦虑提前还清，但月供别超过家庭收入 40%。
- 建立信用：信用卡按时全额还款，征信是长期资产。

## 三、资产配置入门

- 风险分层：活钱层（应急金）、稳健层（存款/债基/理财，1~3 年要用的钱）、增值层（指数基金/股票，5 年以上不用的钱）、保障层（保险）。
- 股债搭配是散户最稳的框架：年龄或风险偏好决定比例（如「100-年龄」的股票比例是粗糙起点）。
- 再平衡：每年一次把比例拉回目标，客观上实现「高抛低吸」。
- 不懂的资产不碰：看不懂底层、承诺保本高收益的，直接排除。

## 四、基金与定投

- 普通人工具箱：宽基指数基金（沪深300、中证500、标普500 等）+ 债券基金 + 货币基金；主动基金选人难，宽基省心。
- 定投平滑成本：固定日期自动扣款，跌时买得多、涨时买得少；适合工资现金流。
- 止盈不止损（宽基定投语境）：达到目标收益率（如 30%）或估值高位分批止盈，收益落袋再开始新一轮。
- 费率敏感：管理费、申购赎回费长期吃收益，同类选低的；持有时长满足条件多用赎回优惠。

## 五、保险配置

- 顺序：先保障后理财；先大人后小孩；先保额后期限。
- 基础四件套：医疗险（报销大额住院）、重疾险（收入补偿）、意外险（杠杆高）、定期寿险（家庭支柱身故责任）。
- 保额参考：重疾 3~5 年收入、寿险覆盖房贷+子女教育；预算有限先买消费型高保额。
- 免责条款、健康告知逐条看：不如实告知是理赔纠纷第一原因。

## 六、常见陷阱

- 追涨杀跌：基金赚钱基民亏钱的根源；用纪律（定投+再平衡）对抗情绪。
- 频繁交易：手续费与择时错误双重损耗。
- 把全部积蓄投单一资产（个股、虚拟币、朋友项目）：单点故障不可承受。
- P2P、保本高息、拉人头返利：收益率显著高于市场且「稳赚」的，先当骗局。
- 忽视通胀与复利：年化 8% 约 9 年翻倍；早开始 5 年，差距是数倍。

## 七、检查清单

- [ ] 记账 3 个月，储蓄率 ≥ 20%
- [ ] 应急金到位（3~6 个月支出）
- [ ] 高息负债已清偿
- [ ] 股债比例明确并每年再平衡
- [ ] 保障型保险已配置，健康告知属实
