# OKR 目标管理指南

## 一、OKR 是什么

- O（Objective）定性、有野心、鼓舞人心；KR（Key Results）定量、可衡量、说明「怎么知道达成了」。
- OKR 管理的是「方向与聚焦」，不是绩效打分工具；与考核强挂钩会导致目标保守、藏真实进度。
- 与 KPI 的区别：KPI 监控既有业务的稳定运行（仪表盘），OKR 驱动突破性改进（导航仪）。二者可并存：日常运营看 KPI，阶段性突破用 OKR。

## 二、写好 Objective

- 一个周期聚焦 1~3 个 O；「什么都想要」等于没有优先级。
- 好的 O 有方向感和完成画面：「打造行业口碑最好的售后体验」优于「提升售后指标」。
- 避免把任务当目标：「上线新客服系统」是手段，背后的 O 应该是「让客户问题 2 小时内闭环」。

## 三、写好 Key Results

- 每个 O 配 2~4 个 KR；KR 必须有基线、目标值、时间边界。
- KR 是「结果」不是「任务」：「客服首响时间从 4h 降到 1h」是 KR；「上线智能路由」是任务。
- 平衡滞后指标（结果）与先行指标（驱动）：NPS 提升（滞后）+ 主动回访覆盖率（先行）。
- 检验：把 KR 念给不相关同事听，他能否判断「达到了没有」？能 → 合格。

```text
O：让客户问题 2 小时内闭环，成为续约的口碑来源
KR1：客服首响时间 P90 从 4h 降至 1h
KR2：问题一次解决率从 62% 提升到 80%
KR3：因售后问题导致的续约流失从 8% 降到 3%
```

## 四、对齐与承接

- 自上而下定方向，自下而上定路径：团队 OKR 要能回答「支撑了公司哪个 O」。
- 跨部门 OKR 用共享 KR 对齐（如增长 KR 由市场+产品共担），避免各说各话。
- 公开透明：全员可见，减少重复劳动与目标冲突。

## 五、执行与复盘

- 周度检查进度与信心指数（1~10），信心骤降比进度落后更值得警惕。
- 中期允许调整 KR 数值（环境变化），但要有记录；频繁改目标 = 没有目标。
- 周期结束打分：KR 完成 0~1.0；0.6~0.7 是健康的挑战性目标，季季 1.0 说明目标定低了。
- 复盘三问：哪些做到了、为什么？哪些没做到、卡在哪？下个周期放弃什么、坚持什么？

## 六、常见失败模式

- OKR 变任务清单：全是「上线 X、发布 Y」，没有结果指标。
- 指标游戏化：只考核 KR 数值导致行为扭曲（如为拉活跃推垃圾通知），需配护栏指标。
- 一年不动：O 写完就锁进抽屉，缺少周检视。
- 与绩效强绑定：员工只报好听的，OKR 失去真相功能。

## 七、检查清单

- [ ] O 少而聚焦，有方向感
- [ ] KR 定量、有基线与截止
- [ ] 团队 OKR 与上级 O 有承接关系
- [ ] 周度有进度与信心指数检视
- [ ] 周期末有复盘，分数用于学习而非惩罚
