# 统计学基础手册

## 一、描述统计

- 集中趋势：均值（对称分布）、中位数（偏态/有极端值）、众数（分类）。
- 离散程度：方差/标准差、IQR（配合中位数）、变异系数（跨量纲比较）。
- 偏态数据汇报「中位数 + IQR」，正态数据汇报「均值 ± 标准差」；先画分布（直方图/QQ 图）再选指标。

## 二、概率与分布

- 二项分布：n 次独立成败试验；泊松：单位时间事件数；正态：连续测量误差与均值近似。
- 大数定律保证频率趋近概率；中心极限定理让样本均值近似正态——这是假设检验的基石。
- 条件概率与贝叶斯：`P(A|B) = P(B|A)P(A)/P(B)`，用于诊断、风控、垃圾邮件等「由果推因」。

## 三、假设检验

- 原假设 H0（无差异），备择 H1；p 值 = 「H0 成立时，出现当前或更极端数据的概率」，不是「H0 为真的概率」。
- 流程：定显著性水平 α（常 0.05）→ 选检验（t 检验/卡方/曼-惠特尼）→ 算统计量与 p → 结论写「拒绝/不拒绝 H0」。
- 多重比较会膨胀假阳性：多组实验用 Bonferroni 或 FDR 校正。
- 统计显著 ≠ 业务显著：样本大时 0.1% 的差异也显著，要看效应量与成本。

## 四、相关与回归

- 相关系数衡量线性关系，范围 [-1,1]；非线性关系（U 型）可能相关系数≈0，先画散点图。
- 相关≠因果：混杂变量、反向因果、幸存者偏差都会造出假相关。
- 线性回归：看系数（业务含义）、R²（解释力）、残差（独立/同方差/正态）；多元回归警惕共线性（VIF）。
- 逻辑回归输出概率，注意类别不平衡时准确率会骗人，看 AUC/召回/精确率。

## 五、AB 实验要点

- 随机分配单元（用户/设备）要稳定，避免同一用户跨组漂移。
- 先算最小样本量（基于基线转化率、最小可检测效应 MDE、α、power），别中途偷看结果就停（peeking 会让假阳性飙升）。
- 指标分层：核心指标（北极星）+ 护栏指标（延迟、崩溃率、投诉率）都要看。
- SRM 校验（样本比是否符合分流量配置）是实验有效性第一道检查。

## 六、常见陷阱

- 辛普森悖论：分组结论与汇总相反，注意分层分析。
- 回归均值：极端值后自然回落，别归功于干预。
- 选择偏差/幸存者偏差：只看留下来的样本会系统性高估。
- p-hacking：反复换指标、切人群直到显著——结论不可信。

## 七、检查清单

- [ ] 分布形态决定用均值系还是中位数系指标
- [ ] 检验方法与数据类型匹配，多重比较已校正
- [ ] 效应量与业务含义一起汇报
- [ ] AB 实验随机性、样本量、SRM 已核查
- [ ] 因果结论有实验或准实验支撑，不只靠相关
