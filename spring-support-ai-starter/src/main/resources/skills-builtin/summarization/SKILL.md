# 内容摘要

## 摘要方法

### 提取式摘要
- 找出关键句
- 保留核心观点
- 删除冗余信息

### 生成式摘要
- 用自己的话总结
- 保持原意
- 简洁精炼

## 摘要结构

```
## 摘要

**主题**: [一句话主题]

**核心要点**:
1. [要点1]
2. [要点2]
3. [要点3]

**结论**: [一句话结论]
```

## 不同场景

- **文章**: 3-5 个要点
- **会议**: 决议 + 待办
- **技术文档**: 功能 + 使用方法
- **报告**: 数据 + 结论 + 建议
