# 家常烹饪指南

## 一、厨房基础

- 锅具三件套：铁锅/不粘锅（炒）、汤锅（煮炖）、电饭煲（饭粥）；一口好刀 + 砧板（生熟分开）。
- 常备调料：盐、糖、生抽、老抽、蚝油、醋、料酒、淀粉、香油、胡椒；嗜辣加豆瓣酱/干辣椒。
- 火候口诀：大火爆炒锁汁、中火煎制上色、小火慢炖入味；油温判断——木筷插入细泡为五成热（炒菜），轻微冒烟为七成热（爆炒）。
- 备菜先行：开火前把所有食材切配好、调料备好（mise en place），炒制只需几分钟。

## 二、肉类处理

- 肉丝/肉片上浆：少许盐、料酒、生抽抓匀，加水淀粉锁水，最后封层油；炒出来才嫩。
- 焯水去腥：冷水下锅加姜片料酒，水开撇沫捞出（排骨、牛肉适用）。
- 红烧通用流程：煎/煸出焦边 → 加生抽老抽糖 → 加热水没过 → 小火炖 → 大火收汁。
- 判断熟度：鸡肉切开无粉红；猪肉全熟；牛排按喜好（全熟更安全）。

## 三、蔬菜与配色

- 绿叶菜大火快炒，出锅前放盐（早放盐出水变蔫）。
- 焯水保色：沸水加少许盐和油，烫 30 秒过凉水，翠绿爽脆。
- 搭配公式：一荤一素一汤；深色菜（西兰花/紫甘蓝）配浅色（山药/木耳）有食欲。
- 蒜蓉、干辣椒炝锅是家常味灵魂：冷油下蒜小火出香，别烧糊。

## 四、米饭与面食

- 米饭：米水比约 1:1.2（手指节法），煮好焖 10 分钟更蓬松；剩饭适合蛋炒饭（隔夜偏干更好炒）。
- 蛋炒饭：蛋液先炒散盛出 → 火腿/配菜炒香 → 下饭压散 → 回蛋 + 盐 + 葱花。
- 面条：水宽火大，点两次凉水；汤面底料 = 生抽 + 香油 + 葱花 + 一勺汤。
- 饺子馅：肉馅分次打水搅上劲，蔬菜最后拌、先加油锁水防出水。

## 五、下饭公式

- 下饭菜三要素：咸鲜打底、微辣提神、带汤汁拌饭（如鱼香、家常、麻婆风味）。
- 鱼香汁（万能）：生抽 2 + 醋 2 + 糖 1.5 + 淀粉 1 + 水 3，兑好最后淋入。
- 一锅出：主食（土豆/粉条）与肉同炖，米饭吸收汤汁，工作日晚餐 30 分钟搞定。
- 快手菜储备：周末卤一锅（鸡翅/蛋/豆干）、冻些肉馅与葱花姜蒜末，工作日直接开炒。

## 六、翻车补救

- 咸了：加土豆/豆腐同煮，或加糖/醋调和，汤类可兑水再调味。
- 淡了：补盐别一次到位，尝一口加一点。
- 糊底：立即换锅（不要刮底），上层好的部分盛出；糊味可加葱段/牛奶吸味（轻微时）。
- 肉柴：next time 上浆 + 大火快炒；已炒老的肉改炖（加啤酒/山楂助软）。
- 菜出水：回锅大火收汁，或勾薄芡兜住。

## 七、安全与卫生

- 生熟砧板/刀具分开，尤其生肉与即食食物。
- 油锅起火：关火 + 盖锅盖窒息灭火，严禁浇水。
- 燃气使用后关阀；抽油烟机炒后多开 3 分钟。
- 剩菜 2 小时内冷藏，24~48 小时内吃完，食用前彻底加热。

## 八、检查清单

- [ ] 开火前备菜、调料、盘子全部就位
- [ ] 肉类上浆/焯水按需处理
- [ ] 调味先少后补，边尝边调
- [ ] 万能鱼香汁/红烧流程能默写
- [ ] 生熟分开、油锅灭火方法知晓
