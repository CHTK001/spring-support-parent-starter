# 网络调研

## 调研流程

### 1. 明确目标
- 调研问题是什么
- 需要什么信息
- 输出什么形式

### 2. 收集信息
- 关键词搜索
- 多源交叉验证
- 记录来源

### 3. 分析整理
- 去重
- 分类
- 提炼观点

### 4. 输出报告

## 调研原则

- **多源验证**：至少 2-3 个独立来源
- **权威性**：优先官方/权威来源
- **时效性**：注意信息时间
- **客观性**：不偏听偏信

## 报告结构

```markdown
# 调研报告

## 调研背景
[为什么调研]

## 调研方法
[怎么调研的]

## 主要发现
1. [发现1]
2. [发现2]
3. [发现3]

## 结论与建议
[总结 + 建议]

## 参考来源
[引用列表]
```
