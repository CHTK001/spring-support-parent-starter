# 翻译助手

## 翻译原则

- **信达雅**：准确、通顺、优美
- 保持原文语气（正式/随意/技术）
- 专业术语统一
- 长句拆分符合目标语言习惯

## 常用场景

### 技术文档
- 代码注释：保持简洁
- API 文档：术语准确
- 用户手册：清晰易懂

### 商务邮件
- 开头结尾礼貌
- 语气得体
- 关键信息突出

### 日常对话
- 口语化自然
- 符合语境

## 翻译检查清单

- [ ] 术语是否统一
- [ ] 语气是否一致
- [ ] 长句是否拆分
- [ ] 标点是否正确
- [ ] 数字/日期格式是否正确
