# SEO 优化指南

## 一、关键词研究

- 从用户语言出发：搜索词 ≠ 行业术语（「手机卡顿怎么办」优于「移动终端性能劣化」）。
- 三类意图：信息型（教程）、导航型（找官网）、交易型（ buy / 价格 / 报名）。交易词转化高、竞争烈，信息词流量大、养权重。
- 工具：Google Keyword Planner、百度指数、5118、Ahrefs/Semrush；关注搜索量、竞争度、长尾词簇。
- 建关键词地图：一页主打一个主词 + 若干长尾，避免多页互抢同一词（自相蚕食）。

## 二、内容优化

- 标题（title）含主词、长度 30 字内、写出点击欲；H1 唯一且与标题一致或互补。
- 首段 100 字内回答搜索意图（精选摘要友好），再展开细节。
- 内容深度胜过数量：一篇覆盖「是什么/怎么做/常见错/对比/FAQ」的长文，胜过十篇浅文。
- 原创度与更新时间影响收录与排名；洗稿、AI 直出无增量价值的内容风险高。
- 多媒体加分：图片带 alt、关键步骤配图/视频，降低跳出率。

## 三、站内结构

- 扁平结构：重要页面距首页 ≤3 次点击；导航、面包屑、相关推荐形成内链网。
- URL 语义化：`/guides/seo-keyword-research` 优于 `/p?id=881`；一个内容一个 URL，规范重定向（301）合并重复页。
- 内链锚文本描述目标页主题，别全站都链「点击这里」。
- 死链定期清理（Search Console / 爬虫工具），404 页给返回入口。

## 四、技术 SEO

- Core Web Vitals：LCP < 2.5s、INP < 200ms、CLS < 0.1；图片懒加载 + 现代 format（WebP/AVIF）、JS 精简。
- 移动优先索引：移动端体验决定排名；响应式设计 + 同一 URL。
- 结构化数据（JSON-LD Schema）：文章、产品、FAQ、面包屑，争取富摘要。
- sitemap.xml 提交、robots.txt 控制抓取；canonical 标签解决参数重复页。
- HTTPS、稳定可用性（99.9%+）、合理缓存策略是基础设施门槛。

## 五、外链与品牌

- 外链质量 > 数量：行业媒体、目录、合作伙伴、优质客座内容是正路；买链、群发是自杀。
- 可被引用的资产最容易获链：原创数据报告、工具、深度指南、信息图。
- 品牌搜索量与直接流量是搜索引擎眼里的信任信号：内容营销 + 社媒联动反哺 SEO。

## 六、监测与迭代

- Search Console：曝光、点击、排名词、收录与抓取错误；Analytics 看落地页转化。
- 核心指标：目标词排名、自然流量、收录率、点击率（CTR）、转化。
- 月度复盘：哪些页面掉了 → 内容过时/竞争加剧/技术问题；哪些词有机会 → 补内容或建专题。
- 算法更新后先看大盘再定责，别把正常波动当事故。

## 七、检查清单

- [ ] 有关键词地图，页面与词一一对应
- [ ] title/H1/首段覆盖搜索意图
- [ ] 内链结构扁平，URL 规范唯一
- [ ] CWV 达标，结构化数据已部署
- [ ] Search Console 与转化数据月度复盘
