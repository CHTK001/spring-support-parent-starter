# 内容营销指南

## 一、策略先行

- 内容营销不是发广告：先提供价值（解决问题/提供情绪/建立信任），商业转化是副产品。
- 明确三要素：给谁看（画像与场景）、看什么（主题域）、看完做什么（关注/留资/购买）。
- 主题域聚焦：围绕「用户常问的 20 个问题」建立内容支柱，而不是追每个热点。
- 阶段目标：冷启动重「被看见」（蹭话题、借平台），成长期重「被记住」（人设与系列化），成熟期重「被信任」（案例与方法论）。

## 二、选题方法

- 需求来源：客服/销售高频问题、评论区追问、竞品高互动内容、搜索下拉词、社群聊天记录。
- 选题四象限：流量型（热点借势）、信任型（干货方法）、转化型（产品对比/案例）、人设型（幕后/观点）。
- 建选题库：随时记录，每周评审打分（预估流量 × 转化相关度 × 制作成本）。
- 系列化 > 单篇：把爆款选题做成连载（「避坑指南 #3」），复用已被验证的注意力。

## 三、爆款结构

- 开头 3 秒定生死：直接抛痛点/反常识/结果前置（「我用这个方法把转化率翻了 3 倍」）。
- 中段给「可拿走的价值」：清单、模板、步骤、对比表；信息密度高但不堆砌。
- 结尾给行动指令：一句「点击主页/评论扣 1/点收藏」比含糊的「希望有帮助」有效。
- 标题公式：数字+利益（「3 个动作，简历回复率翻倍」）、反常识（「别再背单词了」）、身份代入（「程序员转管理必看」）。
- 情绪价值：有用 + 有共鸣（焦虑、爽感、认同）才能被转发。

## 四、内容日历

- 周度排期：固定栏目（周一干货、周三案例、周五互动）培养阅读习惯。
- 节点提前 2~4 周规划：大促、开学季、行业大会；热点预留 20% 弹性 slots。
- 一次生产多次加工：长文 → 拆成 3 条短视频 → 一张信息图 → 一条 newsletter，一鱼多吃。

## 五、分发与渠道

- 平台算法偏好不同：抖音重完播与互动、小红书重搜索与收藏、公众号重转发与深度、知乎重专业长文。
- 同一内容按平台改壳：标题、封面、开头 3 秒、话题标签；不要机械同步。
- 私域沉淀：公域内容 → 引导到社群/企微/邮件列表，转化与复购在私域完成。
- 借力分发：互推、投稿、KOC 种草、行业社群，好内容值得推一把。

## 六、数据复盘

- 过程指标：曝光、完播/阅读完成率、互动率（赞评转/曝光）。
- 结果指标：涨粉、留资、转化、客单；别只盯点赞。
- 每周看数据找规律：哪类选题/标题/封面/发布时间更有效；把结论写回选题库。
- 月度复盘：淘汰低效栏目，加倍投入有效系列；内容资产（搜索排名、系列更新）比单条爆款更值钱。

## 七、常见坑

- 自嗨式内容：讲自己想讲的，不讲用户想听的。
- 只追热点：流量来了留不住，因为没有内容支柱。
- 日更透支：稳定周更 3~5 条高质量 > 勉强日更 7 条平庸。
- 不看数据：凭感觉选题，浪费一半预算。

## 八、检查清单

- [ ] 有明确画像、主题域与转化路径
- [ ] 选题库滚动更新且有评分
- [ ] 每条内容有钩子开头与行动指令
- [ ] 内容日历覆盖固定栏目与营销节点
- [ ] 周度看数据，月度调策略
