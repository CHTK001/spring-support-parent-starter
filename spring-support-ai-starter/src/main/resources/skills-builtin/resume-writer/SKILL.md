# 简历优化

## 简历结构

```
# 个人简历

## 基本信息
- 姓名
- 联系方式
- 求职意向

## 教育背景
- 学校 + 专业 + 时间

## 工作经历
- 公司 + 职位 + 时间
  - 职责描述
  - 项目成果（量化）

## 项目经历
- 项目名 + 时间
  - 技术栈
  - 职责
  - 成果（量化）

## 技能特长
- 技术栈（熟练程度）
```

## 优化要点

- **量化成果**：用数字说话
- **突出重点**：匹配岗位要求
- **简洁明了**：1-2页
- **动词开头**：负责/实现/优化
- **避免空话**：具体做了什么

## 常见问题

- [ ] 太长
- [ ] 太笼统
- [ ] 没有量化成果
- [ ] 技能不匹配
- [ ] 格式混乱
