# 代码审查

## 审查维度

### 1. 正确性
- 逻辑是否正确
- 边界条件处理
- 异常处理是否完备
- 空值/零值处理

### 2. 安全性
- SQL 注入风险
- XSS 漏洞
- 敏感信息泄露
- 权限校验

### 3. 性能
- 循环嵌套是否合理
- 数据库查询是否优化
- 内存泄漏风险
- 不必要的计算

### 4. 可维护性
- 命名是否清晰
- 函数职责是否单一
- 注释是否充分
- 代码重复

## 审查输出格式

```
## 代码审查报告

### 严重问题
- [问题描述] (文件:行号)

### 改进建议
- [建议描述]

### 亮点
- [做得好的地方]
```

## 常见问题检查清单

- [ ] 是否有硬编码的配置
- [ ] 是否有未处理的异常
- [ ] 是否有 SQL 注入风险
- [ ] 函数是否过长（>50行）
- [ ] 是否有重复代码
- [ ] 命名是否见名知意
