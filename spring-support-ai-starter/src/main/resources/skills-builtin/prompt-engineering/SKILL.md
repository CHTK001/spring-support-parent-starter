# 提示词工程

## 提示词结构

```
[角色设定]
你是一个专业的 [角色]。

[任务描述]
请完成以下任务：[具体任务]

[约束条件]
- [约束1]
- [约束2]

[输出格式]
请按以下格式输出：[格式要求]

[示例]
示例1:
输入: [输入示例]
输出: [输出示例]
```

## 技巧

### 1. 明确角色
- 给 AI 设定专业角色
- 让它从专业角度思考

### 2. 具体任务
- 不要模糊
- 拆分成小步骤

### 3. 示例引导
- 给几个示例
- 少样本学习

### 4. 约束条件
- 长度限制
- 格式要求
- 风格要求

## 常见问题

- 输出太长 → 加长度限制
- 跑题 → 明确主题
- 格式不对 → 给模板
- 质量不高 → 加示例
