# 健身训练计划

## 一、目标与起点

- 先定主目标：增肌（热量盈余 + 力量训练为主）、减脂（热量缺口 + 力量保肌 + 有氧辅助）、体能（心肺 + 力量均衡）。
- 新手前 8~12 周收益最快：优先学动作模式（蹲、推、拉、髋铰链、核心），不追求重量。
- 记录基线：体重、围度、力量（如深蹲/俯卧撑最大次数）、静息心率，每 2 周复测。

## 二、动作库（按模式）

- 蹲：深蹲（杠铃/高脚杯）、箭步蹲；推：卧推/哑铃推举/俯卧撑；拉：引体/划船/高位下拉。
- 髋铰链：硬拉、罗马尼亚硬拉、臀桥——练后链与臀部，久坐人群必练。
- 核心：平板支撑、死虫、农夫行走；核心是传力枢纽，不是「卷腹练腹肌」那么简单。
- 每个动作先空杆/自重打磨轨迹：腰背中立、膝盖与脚尖同向、杠铃轨迹贴身。

## 三、训练安排

- 新手全身三分化参考（每周 3 练）：
  - A：深蹲 3×8、卧推 3×8、划船 3×10、平板 3×40s
  - B：硬拉 3×6、推举 3×8、引体/下拉 3×8、死虫 3×10
  - C：箭步蹲 3×10、双杠/俯卧撑 3×力竭、面拉 3×15、悬垂举腿 3×10
- 渐进超负荷：动作标准前提下，每周小幅加重量（2.5~5kg）或加次数；卡住就换重复区间或加休息。
- 组间休息：力量目标 2~3 分钟，肌肥大 60~90 秒；训练时长控制在 60~75 分钟。
- 有氧：减脂期每周 2~3 次 20~30 分钟中低强度（快走/椭圆机/骑行），或 1~2 次 HIIT（不影响力量恢复为限）。

## 四、饮食配合

- 蛋白质：每公斤体重 1.6~2.2g/天（增肌取高值）；鸡蛋、鸡胸、鱼虾、豆制品、乳清都可。
- 减脂：缺口 300~500 kcal/天，每周掉 0.5~1% 体重为宜；掉太快掉肌肉。
- 增肌：盈余 200~300 kcal/天，体重每周涨 0.25~0.5% 为宜；猛吃长的是脂肪。
- 训练前后：训练前 1~2 小时正餐或香蕉；训练后一餐蛋白质 + 碳水（不需要「黄金 30 分钟」焦虑，全天总量更重要）。
- 饮食记录用 app 估两周建立概念，之后凭手感；外食优先 protein + 蔬菜，酱料减半。

## 五、恢复与防伤

- 睡眠 7~9 小时是第一补剂；睡眠不足力量与食欲调控都会崩。
- 训练前动态热身 5~10 分钟（关节活动 + 轻重量组）；训练后静态拉伸放松。
- 疼痛分级：肌肉酸痛（延迟性）正常；关节刺痛、单侧锐痛立即停，排查动作与负荷。
- 每周至少 1~2 天完全休息；连续疲劳、心率升高、表现下滑 = 过度训练信号，减量一周。
- 劳损高发位（肩、腰、膝）：加强薄弱环节（面拉、核心、臀中肌），别只练「镜子肌肉」。

## 六、常见坑

- 只练胸不练背：体态圆肩、肩伤风险；推拉平衡。
- 一上来冲大重量：动作变形代偿，伤在几周后出现。
- 只做有氧不练力量：减脂掉肌肉，代谢下降易反弹。
- 频繁换计划：任何合理计划坚持 8 周都有效，乱换等于从零开始。
- 依赖补剂：蛋白粉只是食物补充；肌酸有证据支持，其余多数锦上添花。

## 七、检查清单

- [ ] 目标明确，基线已记录
- [ ] 每周 3~4 练，推拉腿/全身平衡
- [ ] 动作标准优先，渐进加负荷
- [ ] 蛋白质与热量匹配目标
- [ ] 睡眠与休息日有保障，疼痛会分级处理
